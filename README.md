# 词匣 · 个人提示词库

一个开箱即用的本地提示词管理页面。当前版本不需要安装依赖或配置账号。

## 启动

直接用浏览器打开 `index.html` 即可。也可以在项目目录运行一个静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 当前功能

- 新建、编辑、删除、收藏和归档提示词
- 按分类、标签、标题、正文和适用场景检索
- 分类支持多层文件夹，可在分类旁点击「＋」创建子文件夹；选择父文件夹会显示所有子文件夹中的提示词
- 按最近更新、标题或收藏优先排序
- 使用 `{{变量名}}` 生成填写表单、预览并复制提示词
- JSON 数据导入、合并、替换和导出
- 桌面和手机浏览器响应式布局

首次打开会载入几条示例提示词，方便体验功能。提示词和分类保存在当前浏览器的本地存储中；清理浏览器数据前，请先导出备份。不同浏览器和设备之间不会自动同步。

## 文件

- `index.html`：页面结构
- `styles.css`：界面样式和响应式布局
- `app.js`：交互、模板变量和本地数据管理
- `开发计划与技术方案.md`：完整开发计划、阶段范围和技术方案
