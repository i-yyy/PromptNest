# 词匣 · 个人提示词库

一个免登录的共享提示词库。提示词存放在 Supabase，并缓存在当前浏览器中。

## 启动

直接用浏览器打开 `index.html` 即可。也可以在项目目录运行一个静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 当前功能

- 新建、编辑、删除、收藏和归档提示词
- 按分类、标签、标题、正文和适用场景检索
- 分类支持多层文件夹，可在分类旁点击「＋」创建子文件夹；选择父文件夹会显示所有子文件夹中的提示词
- 按最近更新、标题或收藏优先排序
- 使用 `{{变量名}}` 生成填写表单、预览并复制提示词
- JSON 数据导入、合并、替换和导出
- 桌面和手机浏览器响应式布局

首次打开会载入几条示例提示词，首次成功连接时会上传到云端。其他设备打开网站后会读取共享数据，并每 15 秒检查更新。浏览器仍保留本地缓存；清理浏览器数据前，建议先导出备份。

## 文件

- `index.html`：页面结构
- `styles.css`：界面样式和响应式布局
- `app.js`：交互、模板变量和本地数据管理
- `supabase-config.js`：Supabase 项目 URL 和浏览器 publishable key
- `supabase-setup.sql`：共享数据表及公开读写策略
- `开发计划与技术方案.md`：完整开发计划、阶段范围和技术方案

## Supabase 云端同步

项目 URL 和 publishable key 已配置在 `supabase-config.js`。首次使用前，在 Supabase Dashboard 的 SQL Editor 中运行 `supabase-setup.sql`，再打开网站；页面顶部显示“云端已同步”后即可在其他设备访问同一链接。

本项目选择免登录公开编辑：任何访问网站的人都能查看、添加、修改和删除所有提示词及分类。前端只使用 publishable key；不要把 `secret` 或 `service_role` key 放进浏览器代码。
